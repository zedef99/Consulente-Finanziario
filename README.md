# Agent for Stock Price Retrieval and File Analysis

This project implements a multifunctional agent capable of performing two main tasks:

- **Stock Price Retrieval**: Using function calling, it can obtain real-time stock prices for a specified company.
  
- **Input File Analysis**: A retrieval feature allows the agent to respond based on the content of the provided input file.

The user interface was developed using **Streamlit**. To run the app, download the required libraries (requirements.txt) and execute the command: 
```bash
streamlit run Home.py
